# Session Log

A running, human-readable record of what each Claude Code session accomplished
for this project: reports, audits, investigation summaries, and substantive
task outcomes. It is distinct from the on-disk run log. Prompts and back-and-
forth are not recorded here, only structured outputs.

Convention (defined in CLAUDE.md): newest entry at the top, reverse
chronological. Each entry header is `## YYYY-MM-DD HH:MM UTC — short title`.
Write entries as work completes, then commit and push before the session ends
or hands back. An entry that lives only in the working tree, or only locally,
is treated as lost.
